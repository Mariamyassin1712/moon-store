Moon Store — ملفات متجر إلكتروني تجريبي قابل للنشر
====================================================

محتويات المجلد
- index.html: صفحات المتجر والواجهة العربية.
- style.css: الألوان والتصميم المتجاوب للموبايل والكمبيوتر.
- products.js: المنتجات التجريبية التي يمكن تغييرها أو حذفها.
- script.js: السلة، البحث، الفئات، نموذج الطلب، وتجهيز رسالة واتساب.

مهم قبل النشر
-------------
1) المنتجات والأسعار الحالية أمثلة توضيحية وليست أسعارًا حقيقية أو عروضًا فعلية.
2) المتجر لا يقبل دفعًا إلكترونيًا ولا يخزن الطلبات في قاعدة بيانات.
3) إتمام الطلب يتم عبر نموذج داخل الموقع ثم فتح واتساب برسالة جاهزة. يجب على العميل الضغط على إرسال داخل واتساب حتى يصل الطلب.
4) لا توجد تكلفة شحن ثابتة مضافة؛ تُحدد حسب المحافظة وتتأكدون منها مع العميل.
5) لا تضيفي بيانات بطاقات أو كلمات مرور إلى هذا الموقع.
6) زر المفضلة مؤقت تجميلي، ولا يحفظ قائمة مفضلة بعد تحديث الصفحة.

تعديل رقم واتساب
----------------
افتحي script.js في محرر نصوص وابحثي عن:
const WHATSAPP_NUMBER = "201146499941";
اكتبي الرقم الدولي بدون + أو مسافات.

إضافة أو تعديل المنتجات
-----------------------
افتحي products.js. كل منتج له:
id: معرف فريد لا يتكرر
name: اسم المنتج
category: إحدى الفئات: شنط، إكسسوارات، ساعات، أحذية، نظارات
price: السعر بالجنيه المصري كرقم
emoji: رمز مؤقت للمنتج
description: وصف قصير
badge: شارة اختيارية

مثال:
{id:"bag-007",name:"شنطة بيج",category:"شنط",price:650,emoji:"👜",description:"شنطة للاستخدام اليومي",badge:"جديد"}

يمكنك حذف المنتجات التجريبية واستبدالها بمنتجاتك. الصور الحقيقية تحتاج رفع ملفات صور وإضافة مساراتها في الكود؛ الرموز الحالية مؤقتة.

تشغيل محلي للاختبار
-------------------
- فكّي ضغط الملف ZIP.
- افتحي index.html في Chrome أو Edge.
- أضيفي منتجًا للسلة، غيّري الكمية، ثم افتحي إتمام الطلب.
- استخدمي بيانات اختبار غير حساسة، وراجعي الرسالة قبل إرسالها.
- بعض المتصفحات قد تمنع فتح واتساب في نافذة جديدة؛ اسمحي بالنوافذ المنبثقة أو استخدمي رابط واتساب يدويًا.
- جربي الموقع على الموبايل أيضًا.

النشر المجاني على GitHub Pages
-------------------------------
1) أنشئي حسابًا على https://github.com إن لم يكن لديك حساب.
2) أنشئي مستودعًا جديدًا (New repository)، مثل moon-store، واجعليه Public.
3) ارفعي الملفات الأربعة الموجودة في هذا المجلد إلى جذر المستودع (Code > Add file > Upload files).
4) من Settings > Pages:
   - في Build and deployment اختاري Deploy from a branch.
   - Branch: main، Folder: /(root)، ثم Save.
5) انتظري اكتمال النشر؛ سيظهر رابط الموقع في صفحة Pages، غالبًا بالشكل:
   https://اسم-المستخدم.github.io/moon-store/
6) افتحي الرابط من نافذة خاصة ومن الموبايل واختبري السلة والنموذج وواتساب.

القيود والتكاليف
----------------
- GitHub Pages مناسب لاستضافة واجهة ثابتة، وعادةً لا توجد رسوم استضافة للموقع العام البسيط ضمن حدود الخدمة؛ راجعي الشروط الحالية قبل الاعتماد التجاري.
- رابط GitHub Pages مجاني، لكن الدومين الخاص مثل moonstore.com ليس مجانيًا عادةً.
- لا توجد لوحة تحكم لإدارة المنتجات أو الطلبات. تعديل المنتجات يتم في products.js ثم رفع التعديل للمستودع.
- السلة محفوظة في متصفح الزائر فقط، وليست طلبًا مؤكدًا على خادم.
- لا توجد قاعدة بيانات أو مخزون متزامن أو إشعارات للمالك.
- لا يوجد دفع إلكتروني أو تحصيل أموال عبر الموقع. تفعيل الدفع الإلكتروني يحتاج مزود خدمة مناسبًا، قبول الحساب التجاري، وربما رسوم معاملات/شروط إضافية.
- واتساب هو وسيلة إرسال الطلب؛ لا يُرسل الطلب تلقائيًا قبل أن يضغط العميل زر الإرسال داخل واتساب.
- تحققي من شروط استخدام GitHub Pages وسياسات التجارة الإلكترونية والخصوصية المعمول بها قبل الإطلاق التجاري.
